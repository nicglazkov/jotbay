Three things, and nothing else

Jotbay syncs a folder of notes. It is deliberately not an editor, a database, or somewhere to keep your photos.

Syncs a folder

Save a file and it reaches your other machines seconds later. No button, no commit, nothing to remember. Any file type works, though markdown is the point.

Shows every machine

A menu bar or tray icon that changes when something needs attention, and a feed of what each machine actually did, including the times it failed.

Keeps both versions

Edit one note on two machines and the incoming copy keeps the filename while yours is saved beside it. Sync never stalls, and no version is discarded.

A closer look

Read a note without leaving the app. The reader is read-only by construction, because the commands to write anything don't exist.

The first launch asks one question: where should your notes live? Jotbay can create the private repository for you, clone one that you already have, or adopt a folder that is already a clone.

Install

Download the file for your platform from the latest release. Every installer includes the jotbay command, so choosing the app doesn't cost you the terminal.

macOS Signed

Open the disk image and drag Jotbay to Applications.

Jotbay.dmg

Windows Unsigned

Installs for your user only, so it needs no administrator rights. SmartScreen stops it: choose More info, then Run anyway.

Jotbay_<version>_x64-setup.exe

Linux

Double-click the package, or use the AppImage on distributions without apt.

Jotbay_<version>_amd64.deb
Jotbay_<version>_amd64.AppImage

Homebrew

brew trust nicglazkov/tap
brew install --cask nicglazkov/tap/jotbay

Homebrew refuses to load a cask from a third-party tap until you trust it, so the first line is needed once.

Terminal

curl -fsSL https://raw.githubusercontent.com/nicglazkov/jotbay/main/install/install.sh | bash
jotbay init

On Windows, run install.ps1 the same way. On a headless server, add --no-gui. Jotbay requires git. Only the create-a-repository route also needs gh.

Everything the app shows, scriptable

The apps are front ends over one engine. Nothing behaves differently in a terminal.

Questions worth asking

Where do my notes actually go?

To a git repository that you own, usually a private one on GitHub. GitLab, Codeberg, a self-hosted Forgejo, or a bare repository over SSH all work equally well. There is no Jotbay server and no account with anyone.

The only request Jotbay makes on its own is checking its releases page for updates, and you can point that elsewhere or block it.

Do my machines need to be on the same network?

No, and there is no benefit to it. Machines never contact each other. Each one talks only to the git remote, so a laptop on hotel wifi and a desktop behind a home router behave identically. You need no VPN, and there is nothing to discover or forward.

What happens when two machines edit the same note?

Both versions are kept. The incoming one takes the filename, and yours is saved beside it as note.conflict-<machine>-<time>.md. A conflict is something to tidy up later, never something that stops your notes syncing.

Do I need to know git?

No. Setup asks where your notes should live and handles the rest, and the word "commit" never appears in the interface. If you do know git, everything is real: an ordinary repository that you can inspect, clone, and script against.

What can the folder hold?

Any file type, handled byte for byte. The limits come from git rather than from Jotbay. Anything at or over 100 MB is left uncommitted, because GitHub would reject the push, and Jotbay flags it in the app until you deal with it.

The constraint that actually bites is churn rather than size. Git keeps a near-complete copy of every version of a binary forever, so an image you rewrite twenty times costs that twenty times over on every machine that clones it. Markdown, screenshots, and the occasional PDF are comfortable. Video belongs somewhere else.

How quickly does it sync?

Jotbay syncs a couple of seconds after you stop editing, so a note is usually on your other machines within ten seconds. When nothing is happening it goes quiet rather than polling, and opening a window asks the other machines to report in.

It is still not a real-time collaborative editor. It is built for notes that need to be on the next machine you sit at, not for two people typing in one document.

Why does Windows warn me about the installer?

Because it is not code-signed yet, so Microsoft Defender SmartScreen stops unrecognized apps. Choose More info, then Run anyway. There is no browser warning and no elevation prompt, because Jotbay installs entirely under your own profile. The macOS build is signed and notarized.
