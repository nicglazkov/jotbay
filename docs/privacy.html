Privacy

Jotbay collects no data about you. This page lists each connection that the app makes, and each connection that this website makes.

The app

Jotbay has no server and no account. It sends no data to this project. There is no telemetry and there is no analytics.

Your notes

Your notes stay on your machines and in the git repository that you selected. You are the owner of that repository. If you use GitHub for the repository, the GitHub terms apply to it, and not this page.

The one connection

Jotbay reads api.github.com/repos/<repository>/releases/latest to find a new version. This request contains no data about you and no data about your notes. Jotbay keeps the answer for six hours. Set JOTBAY_TOOL_REPO to a different address, or prevent the connection. All other functions continue to operate.

On your machine

Jotbay writes one preferences file, and a desktop shortcut if you ask for one. It reads and writes no other file outside your vault.

This website

This website has no cookies, no analytics, and no advertisements. It loads no font and no script from a different company.

The connections that this page makes

  • GitHub Pages supplies this page, the stylesheet, and the images. GitHub records the requests to its servers, and the GitHub privacy statement gives the details.
  • api.github.com supplies the version number and the address of each download. The start page makes this request one time. It sends no data about you.
  • A download button sends you to github.com for the file.

Storage in your browser

If you use the light and dark buttons, this website keeps your selection in the local storage of your browser. The value is light or dark. It stays on your machine, and the website sends it to no server. To delete it, clear the site data for this address in your browser.

Questions

Open an issue on the repository. For a security problem, use the security page.
